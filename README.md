# my-ATAL-projects

📱 Integrated Modules

1. Atal Companion Module
Engineered to streamline and maximize project-based learning within ATLs (conducted under NITI Aayog guidelines), this suite routes students through technical categories via curated, step-by-step tracks.

Multi-Track Dashboards: Dedicated pipelines for Robotics, Electronics, and 3D Printing.

Progressive Sandbox Strategy: Each category features three tiers of interactive training:

Tutorial 1: Core software tool configurations (e.g., introduction to design spaces).

Tutorial 2: Baseline system implementations (e.g., LED Blinking configurations using Arduino boards).

Tutorial 3: Comprehensive, dynamic real-world project scenarios.

In-App Media Streaming: Utilizes integrated WebViewer assets to fetch and play targeted YouTube tutorials natively, bypassing third-party application switches and external browser distractions.

Intercepted Back Navigation: Custom block-level conditional hooks manage the hardware back key to regress cleanly through nested dashboards without breaking the application stack.

2. Step Counter Module
A responsive, localized pedometer engine that loops into hardware micro-electro-mechanical components to compute kinetic variables.

Hardware Sourced Telemetry: Binds dynamically to internal smartphone accelerometer registers to parse and structure movement pulses.

KPI Calculus Subroutines: Calculates vital performance statistics:

Cumulative active step counts.

Approximate structural distance coverage (meters/kilometers).

Active baseline calorie expenditure metrics.

Session Controls: Interactive Start, Pause, and Reset routines allow precise tracking window captures.

🛠️ Global Tech Stack
Development Framework: MIT App Inventor 2 (Visual Block-Level Programming)

Layout Framework: VerticalScrollArrangement, Dynamic UI Buttons, Canvas Render Assets.

Sensing & Media Logic: Android Native Pedometer / Accelerometer components, Internal WebViewer wrappers.

Source Format: Combined project archive file (.aia)

Binary Output: Compiled executable installation package (.apk)

⚙️ Installation, Compiling, & Deployment
Follow these phases to import, modify, or host this suite:

Phase 1: Clone Workspace
Clone this repository to your local system environment:

Bash
git clone [https://github.com/your-username/your-repository-name.git](https://github.com/your-username/your-repository-name.git)
Phase 2: Import Source Archive
Head to the web environment: MIT App Inventor Console.

Select Projects from the upper utility bar -> Import project (.aia) from my computer.

Choose the .aia project file present in your cloned repository directory.

Phase 3: Live Debugging & Testing
Download the MIT AI2 Companion application from the Google Play Store onto an Android device.

In the web workstation browser interface, click Connect -> AI Companion.

Scan the displayed QR barcode with your device to stream real-time workspace structural updates, sensor readings, and screen logic.

Phase 4: Binary Packaging
Inside the web workstation interface, select Build -> Android App (.apk).

Once compilation rounds complete, download the .apk target package file or scan the generated installation package barcode to deploy the application directly onto lab mobile assets.
